# My bomz bot

Telegram Mini App о жизни в городе с открытыми путями развития. Cloudflare Worker обслуживает API и статический интерфейс, D1 хранит прогресс игрока.

## Игровая версия 0.4

- Здоровье, сытость, радость, энергия, деньги, репутация, внимание полиции, возраст и дни.
- Еда, лечение, отдых, работа, учёба, покупки, жильё, инвестиции, политика и теневая карьера.
- Доступ к действиям определяется паспортом, аттестатом, жильём, капиталом и связями.
- Герой визуально надевает кроссовки и куртку; велосипед появляется рядом. Улица, укрытие из коробки, комната и квартира имеют разные фоны.
- 39 авторских растровых иллюстраций: четыре состояния героя, четыре локации, 26 действий и пять иконок нижней навигации.
- Постоянная нижняя панель: Главная, Забота, Заработок, Магазин и Путь; внутри разделов — тематические вкладки.
- Все деньги показаны в гривнах. Старые игровые остатки автоматически пересчитываются ×10 один раз, чтобы сохранить прежнюю покупательную способность.
- Жильё открывается последовательно: улица → укрытие → съёмная комната → квартира. Более комфортное жильё усиливает сон и смягчает ежедневное падение здоровья. Комната и квартира требуют аренды; после двух неоплаченных дней игрок возвращается к укрытию.
- Каждый день списывает потребности и аренду, инвестиции и команда дают доход.

## Запуск

`pnpm install`, затем `pnpm dev`. Проверка игровой логики: `pnpm test`. Для локального входа через Telegram нужны секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET` в `.dev.vars`.

## Развёртывание

1. Создать D1 `my-bomz-bot` и указать её ID в `wrangler.jsonc`.
2. `pnpm exec wrangler d1 migrations apply my-bomz-bot --remote`.
3. Добавить два секрета через `wrangler secret put`.
4. `pnpm deploy`.
5. Зарегистрировать `/telegram/webhook` через Telegram Bot API с тем же webhook secret.

Токен бота никогда не хранится в репозитории. Все игровые действия проверяются на сервере, Telegram Mini App `initData` проверяется по подписи.

## Визуал

Иллюстрации находятся в `public/assets/`. На телефоне загружаются сжатые WebP. Главный экран использует готовые варианты героя, поэтому купленные куртка и кроссовки появляются без визуального смещения. Художественное направление и промпты для расширения набора — в `ART_DIRECTION.md`.
